# 家庭维修事项

端口规划：`5114`

纯前端本地单页工具，数据保存在浏览器 localStorage，无需后端。

## 使用

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5114
npm run build    # 生产构建到 dist/
npm run preview  # 预览生产构建 http://localhost:6114
npm test         # 运行自动化测试（vitest + happy-dom）
```

## 功能

- 事项新增、编辑、删除；编辑表单回填原记录
- 按状态（待处理 / 处理中 / 已完成）、位置、优先级筛选
- 按优先级（高→低）、费用（多→少）、时间（新→旧）排序
- 关键词搜索位置、问题描述与备注；筛选/排序/搜索条件随数据持久化，刷新后保留
- 一键状态流转：开始处理 → 标记完成 → 重新打开
- 统计区汇总：未完成数量、处理中数量、未完成预计费用、已完成支出
- 照片仅允许 http/https 地址；图片加载失败时显示“照片无法显示”占位

## 数据与安全

- 所有渲染文本均经 HTML 转义；照片地址经 URL 协议白名单校验，拒绝 `javascript:`、`data:` 等协议
- 表单校验：必填、长度上限、费用非负且最多两位小数、枚举字段白名单
- 提交期间锁定按钮，并对完全相同的内容做短时去重，双击/重复提交不会产生重复记录
- 存储解析具备容错：整体 JSON 损坏、结构错误、单条记录字段缺失或类型错误时，
  自动回退默认值或丢弃坏记录，应用始终可以启动

## 代码结构

- `src/constants.js`：枚举、上限与存储键
- `src/model.js`：纯逻辑——校验、规范化、筛选/搜索/排序、统计、状态流转
- `src/storage.js`：localStorage 读写与损坏恢复
- `src/app.js`：DOM 渲染与事件（事件委托 + 局部刷新）
- `test/`：模型、存储与 UI 集成测试（71 个用例）
